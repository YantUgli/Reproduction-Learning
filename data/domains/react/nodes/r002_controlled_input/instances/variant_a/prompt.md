# Input terkendali (varian A)

Buat komponen React (`export default`) berisi:

- satu `<input>` **terkendali** dengan `aria-label="nama"`, awalnya kosong,
- teks berisi persis `Halo, <nilai input>!` yang ikut berubah saat mengetik,
- saat input kosong, teks itu berbunyi persis `Halo, tamu!`.

Nilai yang tampil di input wajib berasal dari state (input terkendali).
